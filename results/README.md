# Resultados

- `tables/`: tabelas finais ou intermediárias versionáveis quando pequenas.
- `figures/`: figuras destinadas a inspeção e publicação.
- `logs/`: logs e diretórios de execução locais; ignorados pelo Git.

Resultados devem registrar configuração resolvida, seed, versão do dataset e ambiente. Resultados exploratórios não devem ser apresentados como definitivos.
